# Как запустить Sales Copilot у себя

Это версия Foundation: работают регистрация, вход, рабочее пространство и настройки бизнеса. Telegram, ИИ и полноценная CRM ещё не реализованы.

## Что установить

- Node.js 24 LTS.
- Docker Desktop с запущенным Docker Engine и Linux containers. На Linux подойдёт Docker Engine с Compose v2.

## Первый запуск

Распакуйте архив. Откройте терминал в папке `sales-copilot`, где находятся `package.json` и `docker-compose.yml`.

```bash
node scripts/init-env.mjs
docker compose --profile app up -d --build --wait
```

Первый запуск скачает зависимости и соберёт приложение. Устанавливать зависимости через `npm ci` на компьютере для этого способа не требуется: они устанавливаются внутри Docker.

После успешного запуска откройте в браузере адрес:

```text
http://localhost:3000/register
```

Создайте свой аккаунт. Общего логина и пароля нет. Пароль аккаунта должен содержать минимум 12 символов и занимать не более 72 байт.

Используйте именно `localhost`, а не `127.0.0.1`: адрес должен совпадать с настройкой `WEB_ORIGIN`.

Скрипт создаст локальный `.env` со случайными паролями базы и Redis. В архиве нет паролей или данных облачной среды. Сохраняйте свой `.env`: повторный запуск не меняет существующие пароли.

## Остановка и следующий запуск

Остановить, сохранив данные:

```bash
docker compose --profile app stop
```

Запустить снова:

```bash
docker compose --profile app up -d --wait
```

Не добавляйте `-v` к команде `down`: эта опция удаляет тома с данными.

## Если приложение не открылось

Убедитесь, что Docker Desktop запущен. Из папки проекта выполните:

```bash
docker compose --profile app ps -a
docker compose --profile app logs --tail=100 api web
```

Порты 3000, 5432 и 6379 должны быть свободны. Если они заняты другим приложением, остановите его либо настройте порты проекта. При обращении за помощью не отправляйте `.env`, cookies или пароли.
